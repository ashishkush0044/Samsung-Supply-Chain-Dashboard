## 📊 Power BI Sales Dashboard

This repository contains my Power BI Sales Dashboard project, created to analyze sales performance, profitability, customers, products, and regional trends using Microsoft Power BI.

## 🛠️ Tools & Technologies
Microsoft Power BI
Power Query
DAX
Microsoft Excel
Data Visualization

## 📌 Dashboard Features 
Total Sales
Total Profit
Total Orders
Average Order Value
Sales & Profit Analysis
Category-wise Sales
Region-wise Performance
Monthly Sales Trends
Product Performance
Interactive Filters & Slicers

## 🎯 Project Objective
The objective of this project is to transform supply chain and logistics data into an interactive business intelligence dashboard that helps identify trends, monitor key performance indicators, and support data-driven decision making.

## 🗄️ Data Model
A robust **Star Schema** was implemented to connect various fact tables (Inventory, Sales, Production, Procurement, Shipment) with dimension tables (Customer, Date, Facility, Product, Supplier).

## 📈 Key Insights & KPIs
Total Revenue: Calculated net and gross revenue metrics (e.g., 176.95M Gross Revenue).
Supplier Performance: Analyzed average lead times by supplier to identify supply chain bottlenecks.
Shipment Tracking: Monitored total delayed shipments segmented by carrier (Maersk, DHL, DB Schenker, etc.).
Inventory Valuation: Assessed inventory value against specific product lines (Galaxy S24, Galaxy Buds, etc.).
